# 单元测试报告

## 一、测试工具

项目使用 Node.js 内置的 `node:test` 和 `node:assert/strict`。该测试工具无需安装 Mocha、Jest 等第三方依赖，安装 Node.js 后即可运行。测试文件位于 `tests/store.test.js`。

## 二、运行方法

在项目根目录运行：

```powershell
node --test tests/store.test.js
```

## 四、测试代码示例

```javascript
const test = require('node:test');
const assert = require('node:assert/strict');
const { LostFoundStore, createItem, ITEM_STATUS } = require('../src/store.js');

test('T09 寻物状态可以更新为已找到', () => {
  const store = new LostFoundStore([createItem(baseItem, { id: '1' })]);
  const updated = store.updateStatus('1', ITEM_STATUS.FOUND);
  assert.equal(updated.status, ITEM_STATUS.FOUND);
});
```
